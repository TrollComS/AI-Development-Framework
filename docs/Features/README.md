# Features

Crie features a partir do template, use nomes estaveis e mantenha o estado atual. Cada feature referencia regras e decisoes e possui criterios de aceite verificaveis.

## Uso no projeto consumidor

Esta pasta e reservada para features do projeto consumidor onde o ADF foi instalado.

Use o template `docs/AI/Templates/TEMPLATE_FEATURE.md` para criar novas features.
