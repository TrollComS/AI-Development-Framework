# Instruções de agentes do projeto

Este arquivo é um adaptador do ADF. A fonte canônica de contexto do projeto fica em `docs/`.

## Antes de qualquer tarefa

1. Leia este arquivo.
2. Leia `docs/INDICE_DOCUMENTACAO.md`.
3. Leia `docs/Projeto/CONFIGURACAO_IAS.md` e `docs/Projeto/LIMITACOES_EXECUCAO_FEATURES.md`, quando existir.
4. Carregue somente a feature, skill, regras, arquitetura, padrões, decisões e testes relacionados à tarefa.
5. Inspecione o código e o estado atual antes de propor ou realizar alteração.

Siga o [contrato do ADF](docs/AI/Core/ADF_FRAMEWORK.md#contrato-de-instruções-para-agentes), incluindo precedência, segurança, granularidade e regras para ações irreversíveis.

## Documentação e entrega

- `docs/INDICE_DOCUMENTACAO.md` define a leitura mínima; não leia toda a pasta `docs/` sem necessidade.
- Use a rota, o papel e a skill declarados em `docs/Projeto/CONFIGURACAO_IAS.md`.
- Cada feature deve representar o menor incremento funcional coerente, salvo exceção justificada no próprio contexto.
- Ao concluir, informe arquivos alterados, validações, documentos avaliados ou alterados e pendências.
