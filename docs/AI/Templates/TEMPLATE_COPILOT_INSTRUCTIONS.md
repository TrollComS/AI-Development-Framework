# Instruções do GitHub Copilot

Este arquivo fornece contexto de repositório ao Copilot. A fonte canônica do projeto fica em `../docs/`.

- Comece pelo [índice documental](../docs/INDICE_DOCUMENTACAO.md) e siga o [preflight do ADF](../docs/AI/Core/ADF_FRAMEWORK.md#preflight-obrigatório).
- Consulte a [configuração de IAs](../docs/Projeto/CONFIGURACAO_IAS.md) e as limitações locais, quando existirem, antes de planejar, implementar, corrigir ou revisar.
- Carregue somente o contexto relacionado à tarefa; não copie nem recrie regras canônicas neste arquivo.
- Respeite feature, skill, critérios de aceite, padrões, regras, arquitetura, validações e a política de granularidade definidos em `../docs/`.
- Antes de concluir, informe arquivos alterados, validações, documentos avaliados ou alterados e pendências.

Para módulos com diferenças reais, use instruções por caminho em `.github/instructions/**/*.instructions.md`. Essas instruções devem complementar este arquivo e apontar para `../docs/`; não devem substituí-lo.
